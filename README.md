# Nikita Gupta portfolio

Portfolio site for Nikita Gupta, a performance marketer. Built with React, Vite, TypeScript and Tailwind.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Where things live

- `src/design/desk/`: the page and its styles
- `src/config/`: the site content (case studies, experience, industries, tools, certificates, profile)
- `public/` and `src/assets/image/`: images
